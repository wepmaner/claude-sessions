# Claude Sessions

Значок поверх окон для Windows: сколько сессий Claude Code сейчас работает, какие ждут
ответа или решения. Клик по сессии переключает на её терминал; «Закрыть всё и запомнить»
сохраняет список сессий, чтобы открыть их снова.

Ставится через Stash. Настройки и лог ошибок — в `%APPDATA%\ClaudeSessions`.

Сборка: `dotnet build` (.NET 10). Выпуск: `git tag -a vX.Y.Z -m "…" && git push --tags`.
